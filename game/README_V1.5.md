# FocusGrip · V1.5

面向 ADHD 攀岩爱好者的握力控制小游戏 · AdventureX 2026 Game Jam

捏握一个带压力传感器的玩具，实时控制一个小人在攀岩线上往上爬。力度刚好 = 干净抓点上升，力度失控 = 魔性甩飞。既练攀岩指力，又练"把注意力稳住"。

## 玩法

- **力度窗口抓点**：每个抓点有一个目标力度区间（绿区），把握力调进绿区并稳住即判定"抓住"
- **持续保持点（sloper）**：特定抓点需要把力度持续保持在窗口内数秒，进度环填满才算过
- 用力过猛 → 小人魔性甩飞

## 运行

直接用浏览器打开 `focusgrip.html` 即可。

- 按住**空格键**或**鼠标** = 用力
- 松开 = 泄力
- 把握力控制在绿色窗口内完成攀登

## 技术栈

- HTML5 Canvas 纯前端渲染，单文件无依赖
- 键盘/鼠标模拟力度（开发模式）
- 支持 WebSocket 接入 ESP32 + FSR 压力传感器（硬件模式）

## 角色与物理

小人按真实人体比例绘制（7.5 头身），肩/髋两个 Verlet 质点 + 四肢长度约束驱动，手掌与鞋底始终落在岩点上。全部尺寸以身高 `BH` 归一化，`layoutLevel()` 里的 `BH` 是唯一的尺寸开关。细节见 `FocusGrip_角色与物理设计文档.md` 与 `FocusGrip_PRD.md`。

常用开关：

- 关脚点小岩块：把 `USE_FOOT_CHIPS` 改为 `false`
- 调人物大小：改 `BH = Math.max(200, Math.min(CSSH*0.40, 340))`
- 接硬件：改 `INPUT_MODE = 'network'` 和 `WS_URL`

## V1.5 更新内容

在 V1.4 基础上只做攀岩界面 UI 的美术优化（玩法/物理/关卡不变），向手绘攀岩海报风格靠拢：

- **奶油沙砾背景**：攀岩区背景由纯色 tan 改为偏米白奶油底（`#EAE1CB`）+ 粗糙沙砾质感（大小深浅不一的黑色细点点 + 少量碎屑），随攀爬轻微视差滚动，模拟粗糙纸张/岩壁质感
- **手绘岩点**：岩点改为手绘风——深色粗描边轮廓 + 岩点固有色填充 + 岩点内部密布黑色点点点（speckle）+ 螺栓孔小圆环；脚点小岩块同步采用同一手绘风格
- **首页（关卡选择）同步对齐**：首页背景与关卡卡片均改为米白粗糙噪点（噪点贴片改为透明底只含黑点，页面 `#EAE1CB`、卡片略浅 `#F2EBD8` 各自铺同一层噪点，卡片靠细边框+阴影区分）；卡片文字改为深墨色；路线预览点改为小号手绘岩点（固有色 + 深色描边 + 黑色小噪点）

## V1.4 更新内容

- **新增第 6 关 RISI（巨人）**：12 个岩点、6 个持续保持点的终极长线，菜单为 3×2 共 6 关
- **引体上移平滑化**：抓到下一个岩点、把身体拉上去的过程改为 ~0.5s 的缓动（smoothstep）过渡，消除了此前"一帧硬拽上去"的跳跃感（单帧躯干位移由约 94px 降到约 6px）
- **岩点纯色块风格**：去掉描边与高光，改为参考图那样的扁平单色块 + 淡投影 + 不显眼的螺栓暗点，造型多样（豆形/圆角三角/水滴/椭圆等）
- **四肢缝合更流畅**：四肢改用锥形绘制（`limbTaper`），肩/肘/膝及与躯干的接缝连续平滑，无宽度断层
- **适中圆头**：头部尺寸调整为对齐参考图的适中圆头
- **终极物理规则**：双脚始终有着力点、绝不悬空；两只脚不踩同一个岩点；抓下一点时肢体保持弯曲、身体不拉伸变形
