# 像素心流技术文档（检测ADHD倾向以及预防）

## 1. 项目概述

像素心流是一个运行在本机浏览器中的 ADHD 日常自我觉察网页。它把压力传感器、摄像头关键点和用户主动标记汇总为轻量的状态线索，并以像素风界面呈现压力波形、关键点画面和建议气泡。

系统不用于诊断 ADHD、预测医学事件或给用户贴标签。所有提示均为“可以暂停、缓冲或换个姿势”的非诊断式建议。

## 4. 核心模块

### 4.1 压力信号

页面支持三种来源：

- 模拟信号：用于没有接入真实设备时预览波形和界面。
- USB 串口：浏览器通过 Web Serial API 读取压力传感器输出。支持直接数值、`数值#` 和包含 `pressure` 或 `value` 字段的 JSON。
- 巴法云 MQTT：浏览器通过 WebSocket 订阅主题，解析云端推送的压力值。

压力数据会被归一化为 `0–100`，保留最近 120 个样本并绘制到 Canvas 波形图。超过提醒线或发生快速变化时，会写入页面事件时间线。

### 4.2 摄像头多模态关键点

摄像头只在用户手动开启后工作。MediaPipe 模型和推理均在浏览器本地执行。

| 通道 | 模型 | 当前计算方式 |
| --- | --- | --- |
| 面部 | Face Landmarker | 快速眨眼 45%、快速张闭嘴 35%、快速左右摇头 20%。动作越快，数值越高。 |
| 手部 | Hand Landmarker | 手腕位移、关节相对移动、手指弯曲/伸展变化。手部稳定或弯曲变化很小时数值较低。 |
| 身体 | Pose Landmarker | 肩部、手腕与躯干关键点的相对移动。 |

每个通道会在本次摄像头会话中建立约 90 帧的个人基线。页面仅在两个或以上通道同时高于自身基线时显示“多通道变化”提示。该提示代表值得留意和缓冲的时刻，不代表 ADHD 发作、情绪结论或医学判断。

摄像头叠加层会绘制：

- 面部轮廓、眉毛、眼睛、虹膜与嘴部线稿；
- 双手手指骨架与关键节点；
- 实时面部、手部、身体与融合提示数值。

### 4.3 建议气泡

建议区域以从下向上浮动的气泡呈现。建议优先级如下：

1. 用户主动标记“身体排斥感”；
2. 多通道变化；
3. 身体节律明显高于本次个人基线；
4. 压力值超过提醒线；
5. 压力波形快速变化；
6. 日常轻量提示。

建议文案避免要求用户立刻完成任务，优先提供暂停、调整姿势、喝水、离开屏幕或给手脚安全出口等低压力动作。

### 4.4 MiMo 建议接口

前端每 30 秒自动调用一次 `POST /api/suggestion`，也可在建议气泡区域手动触发。

请求只包含抽象数值：

- 当前压力、近 30 秒平均值、范围和趋势；
- 高压事件、波动次数、输入来源与连接状态；
- 面部、手部、身体节律及各自会话基线；
- 多通道变化分数；
- 用户是否主动标记身体排斥感。

服务端调用小米 MiMo 接口，并要求模型仅返回 JSON 格式：`eyebrow`、`title`、`body`、`action`。若外部服务不可用或返回内容异常，页面保留稳定的本地兜底建议。

## 6. 本地运行

### 前置条件

- Windows、macOS 或 Linux；
- Node.js LTS；
- pnpm；
- 建议使用 Chrome 或 Edge，以支持摄像头与 Web Serial API。

### 启动步骤

```powershell
cd "C:\Users\Xu Zhongmao\Documents\Codex\2026-07-25\adhd"
pnpm install
pnpm run dev
```

浏览器打开 `http://localhost:8569/`。终端窗口必须保持运行；关闭终端或按 `Ctrl+C` 会停止本地网页服务。

如需重新下载视觉模型：

```powershell
pnpm run setup:vision
```

生产构建检查：

```powershell
pnpm run build
```

## 7. 配置与安全

MiMo Key 仅应放在 `.env.local`：

```env
MIMO_API_KEY=你的密钥
MIMO_BASE_URL=https://api.xiaomimimo.com/v1
MIMO_MODEL=mimo-v2.5-pro
```

不要将 `.env.local` 上传到 Git、网盘、截图或前端代码。浏览器不直接持有 MiMo Key，调用由 `/api/suggestion` 在本地服务端完成。

巴法云的用户名、UID 和订阅主题在网页设备控制区填写。它们用于连接 MQTT，不应与 MiMo Key 混用。

## 8. 隐私边界

- 不保存摄像头视频、照片、面部身份或手部图像；
- MediaPipe 关键点推理在浏览器本地完成；
- 发送到 MiMo 的是实时汇总数值，不包含原始图像或视频；
- 关闭摄像头后，视频轨道、模型实例和本次会话基线会被清除；
- 用户可以随时关闭摄像头自动分析或 MiMo 自动建议。

## 9. 已知限制

- 光线不足、脸部或手部被遮挡、摄像头角度过低时，关键点质量会下降；
- 手部快速经过画面边缘，或双手交叉时，关键点的对应顺序可能短暂变化；
- 浏览器的帧率、设备性能和网络状态会影响更新频率；
- 个人基线仅适用于当前摄像头会话，刷新页面或重新开启摄像头后会重新建立；
- 这些节律数值只能辅助自我觉察，不能替代医疗、心理或专业支持。

## 10. 后续扩展建议

- 将用户自主确认的状态记录为本地日记，帮助回看触发因素；
- 添加可调节的灵敏度滑块，并保留默认保守阈值；
- 允许用户选择哪些视觉通道参与融合；
- 使用设备端或本机持久化保存匿名的趋势摘要；
- 为不同场景设置不同的轻量建议库，例如学习、工作、休息和通勤。
